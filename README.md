# Voxcraft

An original block-building sandbox game with its own engine, written in C++20. It targets Windows
and macOS from one codebase.

**Status:** active development. The game is playable end to end on macOS. It builds and passes
all tests on macOS (Apple Silicon and Intel) and Windows x64 in CI, but it has not yet been run on
Windows hardware. See [ROADMAP.md](ROADMAP.md).

**What's in the game**
- **Worlds:**
  - Endless deterministic terrain with biomes, caves, ores, trees, ruins, watchtowers, buried
    caches, desert wells and villages.
  - Water and lava that flow, rain and snow, a day/night cycle, and a distant-terrain horizon.
- **Survival:**
  - Tools in four tiers, crafting, kilns, chests, health, hunger, armor, farming, bedrolls,
    buckets, bows and arrows.
- **Creatures (all original):**
  - Grazers, puffbirds, gloomlings, rockmites and settlers who trade.
  - In the Hollow, cinderwisps that shoot ember bolts.
- **Building and transport:** slabs, stairs, fences, panes, doors, trapdoors, gates and walls;
  rails, powered, detector and trip rails, and carts (plain, storage, hopper) that ride them and bump
  into things.
- **The Hollow:** a cavern dimension reached through slate rift gates.
- **Glimmer circuits:** wire, torches, lamps, relays, comparators, watchers, pistons and sticky
  pistons, hoppers, droppers and dispensers.
- **Presentation:** menus, settings, chat with commands, procedurally synthesized original
  audio, particles and an F3 debug overlay.

## Run

```sh
open build/Voxcraft.app                       # macOS
build\Release\voxcraft.exe                    # Windows
./build/Voxcraft.app/Contents/MacOS/Voxcraft --world MyWorld --seed 42   # skip the menus
```

| Control | Action |
|---|---|
| WASD, mouse | move, look (click to capture the mouse) |
| Space / Left Shift | jump (fly up) / sneak (fly down) |
| Left Ctrl or R | sprint |
| F | toggle flying |
| Left (hold) / Right / Middle click | break / place or use (workbench, chest, kiln, lever, button, relay delay) or eat / pick block |
| E | inventory and crafting |
| Q (Ctrl+Q) | drop one (the whole stack) |
| F4 | switch survival / creative |
| 1–9, wheel | hotbar |
| T or / | chat and commands (`/help`) |
| F3 | debug overlay |
| V (remappable) | camera view: first person → behind → facing the player |
| right-click a cart / sneak | ride it / step off (forward pushes); storage and hopper carts open their inventory |
| F5 | save now |
| F11 | fullscreen |
| Esc | pause menu (settings, save and quit to title) |

Worlds are stored in `~/Library/Application Support/Voxcraft/saves` on macOS and
`%APPDATA%\Voxcraft\saves` on Windows. The world is also autosaved every 45 s.

## Engineering highlights
- **Generation:** deterministic and versioned world generation that is bit-identical on x64 and
  arm64. Old generator versions are kept, so existing worlds never change.
- **Storage:**
  - Saves only what you changed; an untouched chunk costs 0 bytes on disk. Structure loot and
    village inhabitants are created lazily, so they don't break that rule.
  - Crash-safe journaled saves with automatic recovery.
  - `vxworld` maintenance tool (info, verify, optimize; dry run and backup).
- **Rendering:** greedy meshing, smooth lighting, cave occlusion culling (−99% draws underground),
  and adaptive memory budgets.
- **Assets:** every asset is original and generated by tools in this repository: textures
  (Python), creature models (OpenSCAD) and sounds (synthesized at startup).

## Supported platforms
- macOS 11+ (Apple Silicon and Intel), Metal
- Windows 10/11 x64, Direct3D 11

## Requirements
- CMake ≥ 3.20
- A C++20 compiler: Xcode command-line tools (clang) or Visual Studio 2022
- Python 3 (asset pipeline, standard library only)
- OpenSCAD (model pipeline)

## Build

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/voxtests        # unit + storage tests
./build/voxbench        # core benchmarks
./build/vxworld info <world-dir>
```

On Windows, use `cmake --build build --config Release` and run `build\Release\voxtests.exe`.

## Packaging

```sh
python3 tools/package.py build          # -> dist/Voxcraft-<version>-<platform>.zip
```

CI builds the packages for macOS (Apple Silicon and Intel) and Windows on every push and
attaches them as workflow artifacts.
